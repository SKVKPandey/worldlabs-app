Best fidelity mode. A 360° equirectangular pano (2:1 aspect ratio) gives the model complete spatial info — recommended for reconstructing a real place. Note: the API only accepts one pano per generation. To combine multiple panos (e.g. interior + exterior), generate each separately and stitch with Marble Studio Compose.
If your image is a 360 pano, leave the box unchecked-this app sets is_pano=true.
Up to 8 normal images. Two sub-modes:
  • Auto Layout (check the box): images must be of the same space, same aspect ratio/resolution, with some overlap.
  • Direction control (uncheck box): tag each image with an azimuth — 0° Front, 90° Right, 180° Back, 270° Left. Up to 4 images works best.
